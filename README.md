# AndroidReminderApp
Reminder app for android. Uni project.

Андроид приложение, присылвает push-уведомление на телефон в заданный промежуток времени.
Имеет возможность дать заголовок уведомлению и добавить текст.
После того как приходит уведомление, можно нажать на него и посмотреть подробную информацию.

This Android app sends push notifications to your phone at set intervals.
You can set a notification title and add text.
When a notification arrives, you can tap it to view detailed information.
